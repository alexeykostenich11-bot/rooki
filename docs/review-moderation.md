# Модерация отзывов

Отзывы хранятся в Redis: pending / published / rejected. На сайте только published. Уведомления и кнопки отправляются лично Алексею. Разрешён только его числовой Telegram user ID; наличие доступа к группе не даёт права публикации.

Подключена база rooki-reviews (Upstash Redis, Free) к production и preview проекта rooki. Поддерживаются UPSTASH_REDIS_REST_URL / UPSTASH_REDIS_REST_TOKEN и переменные интеграции KV_REST_API_URL / KV_REST_API_TOKEN. TELEGRAM_REVIEW_OWNER_ID подтверждён владельцем. Серверные секреты хранятся только в Vercel. Вход в кабинет: команда /reviews лично боту, одноразовая ссылка на 15 минут, после входа защищённая HttpOnly-сессия на 12 часов. Другим Telegram-пользователям доступ не выдаётся.

Проверить getWebhookInfo: Telegram допускает один webhook; нельзя заменять существующий обработчик без переноса его функций. После выпуска setWebhook: https://www.rooki-remont.ru/api/telegram/reviews, secret_token из переменной, allowed_updates: ["callback_query", "message"]. Не сбрасывать updates.

Для получения ID Алексей отправляет /myid лично боту ROOKI. Ответ содержит только ID отправителя; в группах команда не отвечает и никаких прав не назначает. Полученное число необходимо подтвердить с Алексеем перед установкой TELEGRAM_REVIEW_OWNER_ID. Команда заработает только после подключения webhook. Секрет TELEGRAM_BOT_TOKEN уже существует в Vercel, но помечен sensitive и не может быть прочитан через API; для установки webhook необходим безопасный серверный setup либо настройка владельцем с имеющимся токеном. Не просить пользователя публиковать токен в чате.

Одноразовая активация через /api/admin/reviews/setup с секретом ROOKI_REVIEW_SETUP_SECRET: проверяет прежний webhook, подключает новый только если нет конфликта, добавляет подтверждённый владельцем отзыв Анжелики с 5 звёздами, отправляет личную ссылку. Повторная активация блокируется записью в Redis. Старый отрицательный отзыв автоматически не импортируется. Учебные отзывы не оставлять на публичном сайте.

Кабинет /admin/reviews: фильтр статусов, поиск, публикация, отклонение, скрытие опубликованного, восстановление отклонённого. Содержимое отзыва не редактируется. Последние 200 записей; все записи сохраняются в базе без автоматического удаления при заполнении.

Личный счётчик использует ту же базу, но отдельные ключи rooki:stats. Сбор только с согласием посетителя. Случайный идентификатор браузера, без имени/телефона/IP в базе статистики. Уникальные браузеры приблизительно считаются HyperLogLog. Просмотры дедуплицируются по ID события. Дни — Europe/Moscow, ежедневные агрегаты сохраняются 90 дней, общий итог — без срока. Кабинет и просмотры владельца с активной сессией не учитываются. Отказавшиеся посетители и прошлые периоды до включения не учитываются.

При ошибке уведомления запись сохраняется в pending; журнал содержит ID для повторной отправки. Решение и обновление публичного индекса атомарны. Существующие получатели заявок не изменены.
