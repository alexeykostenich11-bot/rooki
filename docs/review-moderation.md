# Модерация отзывов

Отзывы хранятся в Redis: pending / published / rejected. На сайте только published. Уведомления и кнопки отправляются лично Алексею. Разрешён только его числовой Telegram user ID; наличие доступа к группе не даёт права публикации.

До выпуска подключить Upstash Redis к проекту rooki и серверные UPSTASH_REDIS_REST_URL / UPSTASH_REDIS_REST_TOKEN. Настроить TELEGRAM_REVIEW_OWNER_ID (подтверждённый числовой ID Алексея), TELEGRAM_REVIEW_WEBHOOK_SECRET (случайный секрет). Алексей предварительно открывает бота и нажимает Start.

Проверить getWebhookInfo: Telegram допускает один webhook; нельзя заменять существующий обработчик без переноса его функций. После выпуска setWebhook: https://www.rooki-remont.ru/api/telegram/reviews, secret_token из переменной, allowed_updates: ["callback_query", "message"]. Не сбрасывать updates.

Для получения ID Алексей отправляет /myid лично боту ROOKI. Ответ содержит только ID отправителя; в группах команда не отвечает и никаких прав не назначает. Полученное число необходимо подтвердить с Алексеем перед установкой TELEGRAM_REVIEW_OWNER_ID. Команда заработает только после подключения webhook. Секрет TELEGRAM_BOT_TOKEN уже существует в Vercel, но помечен sensitive и не может быть прочитан через API; для установки webhook необходим безопасный серверный setup либо настройка владельцем с имеющимся токеном. Не просить пользователя публиковать токен в чате.

Пока инфраструктура не подключена, эту версию не выпускать. Старый отзыв из Telegram автоматически не импортируется. Перед выпуском проверить отказ постороннему пользователю, повторное нажатие, отклонение и появление только одобренного отзыва. Учебные отзывы не оставлять на публичном сайте.

При ошибке уведомления запись сохраняется в pending; журнал содержит ID для повторной отправки. Решение и обновление публичного индекса атомарны. Существующие получатели заявок не изменены.
