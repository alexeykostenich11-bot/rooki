# Запуск ROOKI на российском хостинге (Timeweb Cloud)

Зачем: сайт на Vercel у части провайдеров не открывается без VPN. На российском хостинге он открывается у всех.
Платформа мастеров (кабинеты, каталог, фото) требует базу данных и хранилище фото, они тоже на Timeweb.

## Что понадобится (всё создаётся в личном кабинете Timeweb Cloud)

1. **PostgreSQL** (раздел «Базы данных»). Нужен адрес подключения вида `postgresql://user:password@host:5432/db`.
2. **Хранилище S3** (раздел «S3-хранилище»). Создай бакет с публичным доступом на чтение. Нужны: адрес сервиса, имя бакета, ключ доступа и секретный ключ.
3. **Приложение** (раздел «Приложения»), тип Next.js, репозиторий `alexeykostenich11-bot/rooki`, ветка `main`.
4. **Домен** .ru (reg.ru или в самом Timeweb).

## Настройки приложения

- Версия Node.js: 22.
- Команда сборки: `npm ci && npm run build`
- Команда запуска: `npm run migrate && npm start`
  (`migrate` создаёт таблицы в базе при первом запуске и применяет обновления дальше, повторный запуск безопасен.)
- Переменные окружения: скопируй из файла `.env.example` и заполни. Обязательные:
  `DATABASE_URL`, `TELEGRAM_BOT_TOKEN`, `NEXT_PUBLIC_SITE_URL`, `S3_ENDPOINT`, `S3_BUCKET`,
  `S3_ACCESS_KEY`, `S3_SECRET_KEY`, `S3_PUBLIC_URL`.
  Если база не пускает без SSL, добавь `DATABASE_SSL=true`, а если ругается на сертификат: `DATABASE_SSL=no-verify`.
- Включи HTTPS (бесплатный сертификат в панели). Без HTTPS вход в аккаунт может не работать.

## Первый вход и админ

1. Открой сайт и зарегистрируйся как обычный пользователь на своей почте.
2. Сделай себя админом одним из способов:
   - в консоли приложения: `npm run make-admin -- твоя@почта.ру`
   - или в веб-панели базы выполни SQL: `update users set role = 'admin' where lower(email) = lower('твоя@почта.ру');`
3. Выйди и войди снова. Тебе откроется страница `/admin`: там анкеты и проекты мастеров на проверке.

## Перед запуском регистрации обязательно

- Заполни данные оператора в `lib/legal.ts` (название, ИНН, адрес, почта) и поставь `LEGAL_CONFIRMED = true`, когда юрист проверил тексты.
- Замени цены-заглушки калькулятора в `lib/pricing.ts` на свои.
- Проверь с телефона на мобильном интернете без VPN.
- Пройди путь мастера сам: регистрация, анкета, проект с фото, одобрение в админке, страница в каталоге.
- Включи резервные копии базы в панели Timeweb.

## Проверка заявок

Заявки с калькулятора и со страниц мастеров приходят в Telegram. Токен бота должен быть задан в `TELEGRAM_BOT_TOKEN`.
Сервер на Timeweb должен иметь доступ к `api.telegram.org`. Если сообщения не приходят, напиши Claude.

## Обновление сайта

Правишь код, `git push`, Timeweb пересобирает приложение сам (включи автодеплой из GitHub в настройках приложения).
Новые таблицы применяются автоматически при запуске командой `npm run migrate`.
